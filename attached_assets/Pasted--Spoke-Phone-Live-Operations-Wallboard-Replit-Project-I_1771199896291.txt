# Spoke Phone — Live Operations Wallboard

## Replit Project Instructions

Use these instructions to build a live wall board dashboard that visualizes real-time call activity, sentiment, and geographic call flow from the Spoke Phone platform.

---

## 1. Project Setup

### Create the Replit project

1. Go to Replit → **Create Repl**
2. Choose template: **Node.js**
3. Name it: `spoke-wallboard`

### Install dependencies

Run in the Replit shell:

```bash
npm init -y
npm install express ws node-cron
npm install -D vite @vitejs/plugin-react react react-dom
```

### Configure `package.json` scripts

Replace the scripts section in `package.json`:

```json
{
  "scripts": {
    "dev": "concurrently \"node server/index.js\" \"npx vite\"",
    "build": "npx vite build",
    "start": "node server/index.js"
  }
}
```

Also install concurrently for dev: `npm install -D concurrently`

### Replit `.replit` config

In the `.replit` file, set:

```
run = "npm start"

[env]
SPOKE_CLIENT_ID = ""
SPOKE_CLIENT_SECRET = ""
```

You'll fill in the Spoke API credentials in the Replit Secrets tab (not in the file).

## 2. Architecture Overview

```
┌─────────────────────────────────────────────────────────┐
│                    SPOKE PHONE                          │
│  Webhooks fire on: call.started, call.ended,            │
│  call.answered, content_analysis.completed              │
└──────────────────┬──────────────────────────────────────┘
                   │ POST /webhook
                   ▼
┌─────────────────────────────────────────────────────────┐
│              EXPRESS SERVER (server/index.js)            │
│                                                         │
│  • Receives Spoke webhooks                              │
│  • Stores today's calls in-memory (Map)                 │
│  • Enriches calls with sentiment from contentAnalysis   │
│  • Broadcasts events to frontend via WebSocket          │
│  • Clears all data at midnight (node-cron)              │
│  • Serves the built React frontend                      │
│                                                         │
│  In-memory state:                                       │
│    todayCalls: Map<callId, callData>                    │
│    dailyStats: { total, active, inbound, outbound,      │
│                  happy, normal, angry, ... }             │
└──────────────────┬──────────────────────────────────────┘
                   │ WebSocket
                   ▼
┌─────────────────────────────────────────────────────────┐
│           REACT FRONTEND (src/App.jsx)                  │
│                                                         │
│  • Connects to WS on load                               │
│  • Renders world map with animated call arcs            │
│  • Live KPI counters                                    │
│  • Sentiment distribution                               │
│  • Recent calls feed                                    │
│  • Resets display at midnight                           │
└─────────────────────────────────────────────────────────┘
```

### Data Flow

1. A call starts → Spoke fires `call.started` webhook → server stores it, broadcasts to frontend → arc appears on map
2. Call ends → Spoke fires `call.ended` webhook → server updates with duration/outcome, broadcasts → counters update
3. AI analysis completes → Spoke fires `content_analysis.completed` webhook → server matches it to the call by `sourceId`, broadcasts sentiment → arc color/sentiment counters update
4. At midnight → `node-cron` clears the in-memory store → frontend receives reset event → everything goes to zero

## 4. Backend Code

### `server/index.js`

This is the main server. It receives Spoke webhooks, manages state, and pushes to the frontend.

```javascript
const express = require("express");
const http = require("http");
const { WebSocketServer } = require("ws");
const cron = require("node-cron");
const path = require("path");
const { getAccessToken } = require("./spokeAuth");
const { phoneToCoords } = require("./geoLookup");

const app = express();
const server = http.createServer(app);
const wss = new WebSocketServer({ server });

app.use(express.json());

// ── In-memory state (resets at midnight) ──
let todayCalls = new Map();
let dailyStats = {
  total: 0, active: 0, inbound: 0, outbound: 0,
  answered: 0, missed: 0,
  happy: 0, normal: 0, angry: 0,
  totalDuration: 0,
};

// ── Broadcast to all connected frontends ──
function broadcast(event) {
  const msg = JSON.stringify(event);
  wss.clients.forEach((client) => {
    if (client.readyState === 1) client.send(msg);
  });
}

// ── On new WS connection, send current state ──
wss.on("connection", (ws) => {
  console.log("Frontend connected");
  ws.send(JSON.stringify({
    type: "init",
    stats: dailyStats,
    recentCalls: [...todayCalls.values()]
      .sort((a, b) => b.timestamp - a.timestamp)
      .slice(0, 30),
  }));
});

// ── Spoke Webhook endpoint ──
app.post("/webhook", (req, res) => {
  const event = req.body;
  const eventType = event.type;

  console.log(`Webhook received: ${eventType} (${event.id})`);

  try {
    switch (eventType) {
      case "call.started":
        handleCallStarted(event);
        break;
      case "call.answered":
        handleCallAnswered(event);
        break;
      case "call.ended":
        handleCallEnded(event);
        break;
      case "call.not_answered":
        handleCallNotAnswered(event);
        break;
      case "call.hungup":
        // Similar to ended, update status
        handleCallEnded(event);
        break;
      case "content_analysis.completed":
        handleContentAnalysis(event);
        break;
      default:
        console.log(`Unhandled event type: ${eventType}`);
    }
  } catch (err) {
    console.error(`Error handling ${eventType}:`, err);
  }

  res.status(200).json({ received: true });
});

function handleCallStarted(event) {
  const call = event.data.call;
  if (call.isInternal) return; // Skip internal calls

  const isInbound = call.direction === "inbound";
  const fromCoords = phoneToCoords(isInbound ? call.contactNumber : call.companyNumber);
  const toCoords = phoneToCoords(isInbound ? call.companyNumber : call.contactNumber);

  const callData = {
    id: call.id,
    direction: call.direction,
    companyNumber: call.companyNumber,
    contactNumber: call.contactNumber,
    status: "active",
    sentiment: null, // Will be filled by content_analysis.completed
    agent: call.directoryTarget?.displayName || call.assignedUser?.firstName || "Unknown",
    company: call.assignedContact?.companyName || null,
    contactName: call.assignedContact
      ? `${call.assignedContact.firstName || ""} ${call.assignedContact.lastName || ""}`.trim()
      : null,
    from: fromCoords,
    to: toCoords,
    startedAt: call.startedAt,
    timestamp: event.timestamp,
    duration: null,
    durationText: null,
    summary: call.summary?.header || null,
  };

  todayCalls.set(call.id, callData);

  dailyStats.total++;
  dailyStats.active++;
  if (isInbound) dailyStats.inbound++;
  else dailyStats.outbound++;

  broadcast({ type: "call.started", call: callData, stats: dailyStats });
}

function handleCallAnswered(event) {
  const call = event.data.call;
  const existing = todayCalls.get(call.id);
  if (existing) {
    existing.status = "answered";
    existing.answeredAt = call.answeredAt;
    broadcast({ type: "call.answered", callId: call.id, stats: dailyStats });
  }
}

function handleCallEnded(event) {
  const call = event.data.call;
  const existing = todayCalls.get(call.id);

  if (existing) {
    existing.status = call.outcome?.status || "ended";
    existing.duration = call.duration ? Math.round(call.duration / 1000) : null;
    existing.durationText = call.durationText || null;
    existing.summary = call.summary?.header || existing.summary;
    existing.company = call.assignedContact?.companyName || existing.company;
    existing.contactName = call.assignedContact
      ? `${call.assignedContact.firstName || ""} ${call.assignedContact.lastName || ""}`.trim()
      : existing.contactName;
    existing.agent = call.assignedUser
      ? `${call.assignedUser.firstName || ""} ${call.assignedUser.lastName || ""}`.trim()
      : existing.agent;

    dailyStats.active = Math.max(0, dailyStats.active - 1);
    if (existing.status === "answered") {
      dailyStats.answered++;
    } else {
      dailyStats.missed++;
    }
    if (existing.duration) {
      dailyStats.totalDuration += existing.duration;
    }
  } else {
    // We missed the started event — create from ended data
    const isInbound = call.direction === "inbound";
    const callData = {
      id: call.id,
      direction: call.direction,
      companyNumber: call.companyNumber,
      contactNumber: call.contactNumber,
      status: call.outcome?.status || "ended",
      sentiment: null,
      agent: call.assignedUser
        ? `${call.assignedUser.firstName || ""} ${call.assignedUser.lastName || ""}`.trim()
        : "Unknown",
      company: call.assignedContact?.companyName || null,
      contactName: call.assignedContact
        ? `${call.assignedContact.firstName || ""} ${call.assignedContact.lastName || ""}`.trim()
        : null,
      from: phoneToCoords(isInbound ? call.contactNumber : call.companyNumber),
      to: phoneToCoords(isInbound ? call.companyNumber : call.contactNumber),
      startedAt: call.startedAt,
      timestamp: event.timestamp,
      duration: call.duration ? Math.round(call.duration / 1000) : null,
      durationText: call.durationText || null,
      summary: call.summary?.header || null,
    };
    todayCalls.set(call.id, callData);

    dailyStats.total++;
    if (isInbound) dailyStats.inbound++;
    else dailyStats.outbound++;
    if (callData.status === "answered") dailyStats.answered++;
    else dailyStats.missed++;
    if (callData.duration) dailyStats.totalDuration += callData.duration;
  }

  broadcast({
    type: "call.ended",
    call: todayCalls.get(call.id),
    stats: dailyStats,
  });
}

function handleCallNotAnswered(event) {
  const call = event.data.call;
  const existing = todayCalls.get(call.id);
  if (existing) {
    existing.status = "missed";
    dailyStats.active = Math.max(0, dailyStats.active - 1);
    dailyStats.missed++;
  }
  broadcast({ type: "call.not_answered", callId: call.id, stats: dailyStats });
}

function handleContentAnalysis(event) {
  // content_analysis.completed contains artifacts from your AI analyzer.
  // The source.id is the Spoke call ID, which lets us join.
  const ca = event.data.contentAnalysis;
  const callId = ca.request?.source?.id;
  if (!callId) return;

  // Extract sentiment from artifacts.
  // Your AI analyzer should produce an artifact with schema "sentiment"
  // containing { sentiment: "Happy" | "Normal" | "Angry" }
  // Adjust this parsing to match your actual analyzer output.
  let sentiment = null;
  if (ca.artifacts && ca.artifacts.length > 0) {
    for (const artifact of ca.artifacts) {
      const data = artifact.data || {};
      // Look for sentiment in the artifact data
      if (data.sentiment) {
        sentiment = data.sentiment; // "Happy", "Normal", or "Angry"
        break;
      }
      // Alternative: check schema name
      if (artifact.schema === "sentiment" && data.value) {
        sentiment = data.value;
        break;
      }
      // Alternative: if your analyzer puts it in a different field
      if (data.customerSentiment) {
        sentiment = data.customerSentiment;
        break;
      }
    }
  }

  if (!sentiment) return;

  const existing = todayCalls.get(callId);
  if (existing && !existing.sentiment) {
    existing.sentiment = sentiment;

    // Update sentiment counters
    const key = sentiment.toLowerCase();
    if (key === "happy") dailyStats.happy++;
    else if (key === "angry") dailyStats.angry++;
    else dailyStats.normal++;

    broadcast({
      type: "sentiment.update",
      callId,
      sentiment,
      stats: dailyStats,
    });
  }
}

// ── Midnight reset ──
cron.schedule("0 0 * * *", () => {
  console.log("Midnight reset — clearing daily data");
  todayCalls.clear();
  dailyStats = {
    total: 0, active: 0, inbound: 0, outbound: 0,
    answered: 0, missed: 0,
    happy: 0, normal: 0, angry: 0,
    totalDuration: 0,
  };
  broadcast({ type: "reset", stats: dailyStats });
});

// ── Health check ──
app.get("/health", (req, res) => {
  res.json({
    status: "ok",
    uptime: process.uptime(),
    calls: todayCalls.size,
    stats: dailyStats,
    wsClients: wss.clients.size,
  });
});

// ── Serve React frontend (production) ──
app.use(express.static(path.join(__dirname, "../dist")));
app.get("*", (req, res) => {
  res.sendFile(path.join(__dirname, "../dist/index.html"));
});

// ── Start ──
const PORT = process.env.PORT || 3000;
server.listen(PORT, () => {
  console.log(`Spoke Wallboard server running on port ${PORT}`);
  console.log(`Webhook URL: https://YOUR-REPLIT-URL.replit.app/webhook`);
});
```

### `server/spokeAuth.js`

For fetching content analysis data if you want to poll (optional — webhooks are primary).

```javascript
const querystring = require("querystring");

let cachedToken = null;
let tokenExpiry = 0;

async function getAccessToken() {
  if (cachedToken && Date.now() < tokenExpiry) return cachedToken;

  const res = await fetch("https://auth.spokephone.com/oauth/token", {
    method: "POST",
    headers: { "Content-Type": "application/x-www-form-urlencoded" },
    body: querystring.stringify({
      client_id: process.env.SPOKE_CLIENT_ID,
      client_secret: process.env.SPOKE_CLIENT_SECRET,
      grant_type: "client_credentials",
    }),
  });

  const data = await res.json();
  cachedToken = data.access_token;
  tokenExpiry = Date.now() + (data.expires_in - 60) * 1000;
  return cachedToken;
}

module.exports = { getAccessToken };
```

function phoneToCoords(phoneE164) {
  if (!phoneE164) return { lat: 39.8, lng: -98.5, name: "Unknown" };
  const num = phoneE164.replace(/[^0-9]/g, "");

  // Try US area code
  if (num.startsWith("1") && num.length >= 4) {
    const area = num.substring(1, 4);
    if (US_AREA_COORDS[area]) {
      const c = US_AREA_COORDS[area];
      // Small random offset so overlapping calls don't stack
      return {
        lat: c.lat + (Math.random() - 0.5) * 0.5,
        lng: c.lng + (Math.random() - 0.5) * 0.5,
        name: c.n,
      };
    }
  }

  // Try country codes (3-digit, 2-digit, 1-digit)
  for (const len of [3, 2, 1]) {
    const code = num.substring(0, len);
    if (COUNTRY_COORDS[code]) {
      const c = COUNTRY_COORDS[code];
      return {
        lat: c.lat + (Math.random() - 0.5) * 2,
        lng: c.lng + (Math.random() - 0.5) * 2,
        name: c.name,
      };
    }
  }

  return { lat: 39.8, lng: -98.5, name: "US" };
}

module.exports = { phoneToCoords };

### `src/hooks/useWebSocket.js`

```javascript
import { useEffect, useRef, useCallback, useState } from "react";

export function useWebSocket(onMessage) {
  const wsRef = useRef(null);
  const [connected, setConnected] = useState(false);
  const reconnectTimer = useRef(null);

  const connect = useCallback(() => {
    const protocol = window.location.protocol === "https:" ? "wss:" : "ws:";
    const ws = new WebSocket(`${protocol}//${window.location.host}`);

    ws.onopen = () => {
      console.log("WebSocket connected");
      setConnected(true);
    };

    ws.onmessage = (evt) => {
      try {
        const data = JSON.parse(evt.data);
        onMessage(data);
      } catch (e) {
        console.error("WS parse error:", e);
      }
    };

    ws.onclose = () => {
      console.log("WebSocket disconnected, reconnecting in 3s...");
      setConnected(false);
      reconnectTimer.current = setTimeout(connect, 3000);
    };

    ws.onerror = (err) => console.error("WS error:", err);

    wsRef.current = ws;
  }, [onMessage]);

  useEffect(() => {
    connect();
    return () => {
      clearTimeout(reconnectTimer.current);
      wsRef.current?.close();
    };
  }, [connect]);

  return { connected };
}
```

## 6. Spoke Webhook Setup

Once your Replit app is deployed, you need to register the webhook URL in Spoke.

1. Go to **Spoke Account Portal** → https://account.spokephone.com
2. Navigate to **Other → Developers → Webhooks**
3. Create a new webhook with:
   - **URL**: `https://YOUR-REPLIT-URL.replit.app/webhook`
   - **Events** — subscribe to all of these:
     - `call.started`
     - `call.answered`
     - `call.ended`
     - `call.hungup`
     - `call.not_answered`
     - `content_analysis.completed`
4. Save the webhook

### Content Analysis (Sentiment) Setup

The `content_analysis.completed` event fires when your AI analyzer finishes processing a call. The server matches it back to the call using `source.id` (which is the Spoke call ID).

Your analyzer artifacts should include a sentiment value. The server code looks for:
- `artifact.data.sentiment` — expects `"Happy"`, `"Normal"`, or `"Angry"`
- Or `artifact.schema === "sentiment"` with `artifact.data.value`

Adjust the `handleContentAnalysis` function in `server/index.js` to match your actual AI analyzer's output format.

## 7. Deployment Notes

### Replit Always-On
- Use **Replit Deployments** (paid) to keep the server running 24/7
- Without this, the Repl will sleep after inactivity and miss webhooks

### TV Display Setup
- Open the Replit app URL in Chrome on the office TV
- Press **F11** for fullscreen
- The dashboard auto-reconnects if the WebSocket drops
- Consider using a Chrome kiosk mode extension for unattended operation

### Timezone
- The midnight reset uses server time. Set `TZ` environment variable in Replit if needed:
  ```
  TZ=America/New_York
  ```
- Or use `node-cron` with timezone: `cron.schedule("0 0 * * *", fn, { timezone: "America/New_York" })`

### Scaling Considerations
- The in-memory store works fine for a single day of data (even millions of calls — a Map with call IDs as keys is efficient)
- If you want historical data or multi-day views later, add a database (Replit has built-in PostgreSQL or you could use Redis)
- WebSocket broadcasts are lightweight — a few hundred events per minute is trivial
